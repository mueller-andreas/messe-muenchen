# Daten-Snapshot (optional)

Die Seite lädt die Daten normalerweise live vom
[Open Data Portal München](https://opendata.muenchen.de/dataset/veranstaltungen-der-messe-muenchen).

Als Offline-Fallback kann hier eine Kopie der Original-CSV abgelegt werden:

```
data/veranstaltungsdaten.csv
```

Quelle: Datensatz „Bisherige Veranstaltungen der Messe München – Veranstaltungsdaten ab 2018“,
Herausgeber: Messe München GmbH, bereitgestellt über das Open Data Portal der
Landeshauptstadt München. Lizenzhinweise siehe Datensatzseite.
